# Historical note — beta.6

Current release, feature contract and installation: [root README](../README.md). Latest beta.8 real-HA findings and outstanding issues: [BETA8_VALIDATION.md](../BETA8_VALIDATION.md). `main` must not be promoted until the open checks are resolved.
